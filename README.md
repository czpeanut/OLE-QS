# OLE-QS — 線上題庫系統

Online Exam / Question-bank System：把國中考古題的掃描影像轉成結構化題庫，依 108 課綱分類，供教師檢索與自由組卷、匯出考卷。

## 現況

規劃階段。開發計畫見 [`docs/development-plan.md`](docs/development-plan.md)。

## 核心流程

```
考古題原圖 → 影像前處理 → 版面/圖框偵測 → VLM 擷取為結構化題目
          → 人工校對 → 課綱自動分類 → 去重入庫
          → 教師檢索/篩選 → 題籃組卷 → 匯出 PDF / Word（試題卷、答案卷、詳解卷）
```

## 下一步

依開發計畫「附錄 A」，先完成擷取管線的技術驗證（PoC），量測真實掃描檔的擷取正確率與成本，再進入正式開發。
