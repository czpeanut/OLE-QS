# 高中題庫：逐題分章節、建立題型目錄（交接文件）

給執行 agent。工作方式和第三輪萃取一樣：**你自己逐題讀、逐題判斷，分批交件**。不用寫分類程式，也不要呼叫任何模型 API。

## 0. 交接包裡有什麼

雲端根目錄 `OLE-QS_高中分章節_工作包_1117.zip`（分段時用 `cat …part* > 包.zip` 合併）：

| 路徑 | 用途 |
|---|---|
| `work/<批次>.jsonl` | **待分類的題目**。38 批、1,498 卷、47,867 題，一行一題，欄位見第 1 節 |
| `work/batches.json` | 每批的科目、卷數、題數、附圖所在的雲端交件包與 SHA-256 |
| `scripts/check_senior_labels.py` | 交件前自我檢查，**結束碼要是 0** |
| `scripts/senior_label_export.py` | 工作檔是怎麼產生的（參考用，不必執行） |
| `reference/junior.yaml` | 國中單元表，格式參考 |
| `reference/math_patterns_7-1_1-1.yaml` | 國中數學題型目錄範例，題型寫法參考 |
| `HANDOFF.md` | 本文件 |

**題目來源只有 `work/*.jsonl` 這一份。**
- 它由題庫定版 `data/high_school/bank/` 匯出，含 11-15～16 的人工校對。
- 不要改用第三輪交件包裡的 YAML，版本可能不同。

**附圖**：jsonl 只寫附圖檔名（`figures`、選項的 `figure`）。
- 需要看圖時，到雲端「第三輪交件」下載 `batches.json` 裡 `figures_package` 那一包，核對 `figures_package_sha256`，再到它的 `assets/` 找同名檔。
- 也可以看包裡 `sources/` 的原卷 PDF。
- 公民第 2 批、地科第 2 批的交件包沒附原卷 PDF，看 `assets/` 的附圖即可。
- 大部分題目只看文字就能判斷，不必每題看圖。

## 1. 工作檔欄位（`work/<批次>.jsonl`）

```json
{"id": "doc_108_台中_台中一中_數學_g10s2e1_s1_1",   ← 題目 id，交件時照抄
 "paper_id": "doc_108_台中_台中一中_數學_g10s2e1",
 "subject": "數學",            ← 科目：數學 物理 化學 生物 地科 歷史 地理 公民與社會 國文
 "grade": 10, "semester": 2, "exam_seq": 1,   ← 高一下第 1 次段考
 "course": null,                ← 選修課名（數A、選修物理I…）；null＝必修
 "book_hint": "必修（高一下學期）",  ← 建議的冊（第 2.2 節）
 "school": "台中一中", "year_roc": 108,
 "scope_note": null,            ← 卷上印的考試範圍（595 卷有），判斷時優先參考
 "title": "…", "section_name": "一、單一選擇題", "number": 1,
 "type": "single",              ← single／multiple／fill／calc
 "group_stem": null,            ← 題組文章（題組子題才有）
 "stem": "…", "options": [{"label": "A", "content": "…", "figure": "…png（有圖才有）"}],
 "figures": [], "answer": ["D"], "explanation": "…（截前 400 字）"}
```

公式是 LaTeX（`$…$`），畫線處是 `<u>…</u>`。

## 2. 第一步：建立高中單元表 `senior.yaml`

**先交單元表，督察看過才開始逐題標。**

### 2.1 格式

```yaml
source:
- <每一冊目錄的出處：出版社官網、課綱對照表網址…>
subjects:
  數學:
  - book: 第一冊                     # 冊名
    covers: 必修（高一上學期）        # 對應的 book_hint，可以列多個
    units:
    - code: MA-1-1-1                  # 單元代號：全科唯一，交件時用這個
      chapter_title: 數與式
      title: 實數
      aka: [數線與實數]               # 各出版社不同的名稱，選填
  物理:
  - book: 選修物理I
    covers: 選修物理I
    units: […]
```

- 科目名稱一定用：數學、物理、化學、生物、地科、歷史、地理、公民與社會、國文。
- 單元到「節」，國文到「課」。
- 各出版社（龍騰、翰林、南一、康熹、全華等）章節編排不同，**單元表只列一套標準單元**，寫法如下：
  - 以龍騰版的目錄為主幹，其他版本的不同名稱放進 `aka`；
  - 某版本獨有的節併到最接近的單元。
- 代號格式：`<科目縮寫>-<冊序>-<章>-<節>`。
  - 縮寫用 MA 數學、PH 物理、CH 化學、BI 生物、ES 地科、HI 歷史、GE 地理、CI 公民、ZH 國文。
  - 選修冊的冊序用 S1、S2…，例如 `PH-S1-2-3`；數A、數B、數甲、數乙用 A3、A4、B3、B4、J1、J2、Y1、Y2。
- **目錄要查實際出版的教科書，在 `source` 寫出處，不要憑記憶補。** 查不到的冊寫 `units: []` 並說明。

### 2.2 一題屬於哪一冊

- **有 `course`**（選修）：冊就是那門選修，`book_hint` 已經寫好，**不要看年級**。同一門選修在不同學校排在不同年級，例如選修生物I 在高一、高二、高三都有。
- **沒有 `course`**（必修）：`book_hint` 只寫年級學期，要你對應到實際的冊。
  - 學校可能把必修冊挪到別的學期上，以 `scope_note` 和題目內容為準。
  - 自然科必修（基礎物理、基礎化學、基礎生物、基礎地科）各校排法不同，特別注意。
- 跨冊的總複習卷照題目內容分，可以分到不同冊。

## 3. 第二步：逐題分章節（每批一個檔）

每題選一個單元，交 `labels/<批次>.jsonl`，一行一題，**批次檔名和工作檔相同**：

```json
{"id": "doc_108_台中_台中一中_數學_g10s2e1_s1_1", "unit": "MA-2-1-3", "confidence": "high", "pattern": "T04", "difficulty": 2, "note": ""}
```

| 欄位 | 規則 |
|---|---|
| `id` | 照抄工作檔；**每題剛好一行，不能漏、不能重複** |
| `unit` | `senior.yaml` 裡的單元代號。判斷不了寫 `null`，**`note` 必須寫原因**（例如「題目缺圖無法判斷」「跨三章綜合題」） |
| `confidence` | `high`：明確只屬於這單元；`medium`：主要考這單元但也用到其他單元；`low`：沒把握 |
| `pattern` | 只有數學、物理、化學、生物、地科要填（第 4 節）。題型目錄裡沒有合適的寫 `OTHER`。其他科不填 |
| `difficulty` | 同上五科才填，1～5（1 基本定義、3 一般段考題、5 需要多步推理或跨單元的難題） |
| `note` | 選填。題目有錯、缺字、缺圖也寫在這裡，督察會另外處理 |

判斷規則：

- **依「這題考的觀念或方法」分**，不依情境或關鍵字。例如用到三角函數的物理斜面題，分在物理的力學單元。
- 卷上有 `scope_note` 時，題目原則上要落在範圍內。超出範圍要有把握，並在 `note` 說明。
- 題組子題通常同一單元，分開時檢查程式會提醒，確認無誤即可。
- 「承上題」要看前一題。
- **不准改題目內容**。發現題目本身有問題，只在 `note` 記下來。

## 4. 第三步：題型目錄與逐題題型（數學、物理、化學、生物、地科）

做法：同一單元的題目累積到一定量後歸納題型，再回頭逐題標。建議一科的章節全部標完後，按單元把題目集中起來做。

- 每個單元一份 `senior_patterns/<科目>/<單元代號>.yaml`：

```yaml
unit: {subject: 數學, code: MA-2-1-3, title: …}
status: draft
unit_questions: 612          # 這個單元的題數
types:
- code: T01
  name: 一維數據的平均數與標準差計算
  desc: 由原始資料或次數分配表求算術平均數、標準差；或判斷資料變動後統計量的增減。
- code: T02
  …
```

- 一個單元 5～20 個題型，**依解法分，不依情境分**；`name` 15 字內，`desc` 一句話說明怎麼考、用什麼方法。範例見 `reference/math_patterns_7-1_1-1.yaml`。
- 每題選一個題型代號；都不合適寫 `OTHER`。
- 修整標準：
  - 一個單元 `OTHER` 超過 10%：從這些題補新題型。
  - 單一題型超過 30%：太雜，要拆開。
  - 修改題型目錄後，受影響的題要重標。
- 題型目錄可以邊做邊增補，但**代號一旦交出就不要改意思**，只能新增。

## 5. 交件

1. **先交單元表** `senior.yaml`，督察核可後才逐題標。
2. 依序：數學 → 物理 → 化學 → 生物 → 地科 → 歷史 → 地理 → 公民與社會 → 國文。
   - 每科的章節全部標完、題型也做完才交，一科一包。
3. 交件前自我檢查，**結束碼要是 0**：

```bash
python scripts/check_senior_labels.py --work work --units senior.yaml \
    --patterns senior_patterns --labels labels/數學_*.jsonl
```

4. 自我抽驗：每科隨機抽 50 題（種子 20261117），重新判斷一次。
   - 不一致的修正，寫進 `REPORT_<科目>.md`，列出 id 與修正內容。
5. 封裝 `UNITS_<科目>.zip`，內含：
   - `labels/<科目>_*.jsonl`
   - `senior_patterns/<科目>/`
   - 當時的 `senior.yaml`
   - `REPORT_<科目>.md`
6. 上傳到雲端「第三輪交件」，每段 ≤5MB。
7. 在 `ROUND3_進度回報` 寫一筆：科目、題數、`unit: null` 比例、`OTHER` 比例、自我抽驗不一致數、檢查程式最後兩行。

`REPORT_<科目>.md` 至少要有：
- 每冊每單元的題數；
- `unit: null` 的題目清單與原因；
- 各單元 `OTHER` 比例；
- 自我抽驗結果；
- 在 `note` 記錄的題目問題清單。

## 6. 驗收

- 督察每科抽 30 題重新判斷。單元錯誤或題型錯誤合計超過 5%（2 題以上）退回該科。
- 退回時會列出錯誤的題與原因，修正規則後**整科重新檢視**，不是只改被點名的題。

## 7. 規則

- 一律用中文回報。照實回報，做不完、不確定就直接寫出來。
- 不改題目、不改工作檔、不改檢查程式。
- 只有這些情況才停下來回報：
  - 某一冊查不到任何版本的目錄；
  - 某科超過 15% 題目分不到單元；
  - 檢查程式本身出錯。

  其他問題照規則標 `null`／`OTHER` 照交，不要停工。
