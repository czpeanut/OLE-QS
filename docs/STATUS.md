## 已完成

**擷取管線**（`scripts/`）
- `pdf_ingest.py` — PDF 分流：原生數位／掃描／空白頁，圖形以頁面區域渲染取出
- `extract.py` — 原生數位卷 → 結構化題目；含雙欄閱讀順序、表格版面還原、答案掛載
- `parse_answer_key.py` — 答案卷解析，支援四種版型，排除配分表與空白答案卷
- `validate_extraction.py` — 結構驗證（配分總和、題號連續性、選項、共用素材）
- `generate_answers.py` — 多模型交叉作答（**已寫好，尚未實跑，需 API key**）

**應用**（`apps/api/`）
- 資料模型、SQLite + FTS5 trigram 中文搜尋
- 品管閘門、匯入器、Markdown+LaTeX 渲染
- REST API、單頁介面（檢索 → 題籃 → 匯出三種卷）

## 關鍵決策（**動手改之前先讀這段**）

這些不是隨意選的，都是撞牆撞出來的。改動前請確認你理解原因。

| 決策 | 為什麼 |
|---|---|
| **捨棄有問題的題目，不做人工校對** | 來源卷很多、題目可替換，丟一題的成本遠低於修一題。這個決定讓原本估計 17 小時的校對工作消失 |
| **出處掛在題目上，不是文件上** | 題庫的用途是跨卷重組。存在文件層的話，去重合併、改編題、原文件被刪都會讓出處失效 |
| **被剔除的題目保留不刪除** | 剔除率是管線健康度指標；從 8% 跳到 40% 代表管線壞了，不是卷變難了 |
| **路徑優先於卷頭解析** | 很多考卷不印學校與學年度，那些資訊只在 `年級-學期/縣市/學校.pdf` 的目錄慣例裡 |
| **原生數位 PDF 不轉圖再 OCR** | 文字圖層可無損取出。轉圖再辨識是把已經正確的文字弄髒再猜回來 |
| **圖形用頁面區域渲染，不抽 XObject** | 抽取會丟失 SMask 導致整張變黑，且同一張圖被重複放置時只會拿到一張 |
| **規則式擷取，不用模型** | 考卷版面規律性高；規則涵蓋不到的由品管閘門剔除。**寧可漏抓，不可錯抓** |

## 下一步（依價值排序）

1. **補答案** — 197/1008 是最大短板。沒答案的題目對老師價值有限。
   兩條路：去要答案卷（最可靠，同時是量測 AI 準確率的校準資料），
   或跑 `generate_answers.py`（已寫好，需 `GEMINI_API_KEY` + `ANTHROPIC_API_KEY`）
2. **看那 193 題為什麼被剔除** — 資料都在（`status='rejected'` 帶原因），
   統計出主要型態就知道值不值得為它加規則
3. **掃描件路線** — 9 份掃描 PDF 目前完全沒處理，需要 VLM 擷取
4. **課綱分類表** — 現在的分類標籤是擷取到的章節名，尚未對應 108 課綱正式代碼
5. Word 匯出、智慧組卷（依權重自動抽題）

## 已知問題

- **答案覆蓋率 20%** — 多數新卷是純題目卷
- **收錄率 84%**，低於熟悉版面的 95%。這是預期的（8 縣市、多種沒見過的排版），不是退步
- **掃描件未支援**
- 國文的字音字形題在部分版面仍擷取不全
- 分類標籤未對應正式課綱代碼
