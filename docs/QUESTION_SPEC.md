# OLE-QS 題目格式規範（交接用）

給所有要「產出題目」的人與 agent：考古題轉檔、自命題（原創）、修正題都照這份。
考古題整份原卷的 YAML 細節（出處、大題、附圖座標）另見 `docs/QUESTION_FORMAT.md`（國中）、`docs/HIGH_SCHOOL_HANDOFF.md`（高中）；
本文件是**每一題**的共通規則，以及自命題／修正題使用的 JSONL 格式。

> 只產出檔案。**不要改 repo 的 `data/bank/`、`data/export/`、Supabase**；金鑰不要印出、不要寫進交件。
> 腳本、設定檔一律不要手改；有疑問寫在回報裡。

---

## 1. 一題的資料（JSONL，每行一題）

```json
{"id": "orig_ph_b0_PH-1-2-1_03",
 "subject": "物理", "grade": 10, "semester": 1, "book": "物理（全）",
 "unit": "PH-1-2-1", "unit_title": "牛頓運動定律",
 "type": "single", "difficulty": 3,
 "group_stem": null,
 "stem": "質量 $2\\,\\text{kg}$ 的物體受水平力 $6\\,\\text{N}$ …，則加速度為何？",
 "options": [{"label": "A", "content": "$1\\,\\text{m/s}^2$"}, {"label": "B", "content": "$3\\,\\text{m/s}^2$"},
             {"label": "C", "content": "$6\\,\\text{m/s}^2$"}, {"label": "D", "content": "$12\\,\\text{m/s}^2$"}],
 "answer": ["B"],
 "explanation": "由 $F=ma$ 得 $a=F/m=3$，選 (B)。(A) 把質量當成… (C) … (D) …",
 "pattern": "T03", "pattern_name": "牛頓第二定律求加速度"}
```

| 欄位 | 必填 | 規則 |
|---|---|---|
| `id` | ✔ | 全題庫唯一。自命題：`orig_<科目縮寫>_b<冊>_<單元代號>_<兩位序號>` |
| `subject` | ✔ | 國中：國文／英語／數學／自然／社會；高中：國文／數學／物理／化學／生物／地科／歷史／地理／公民與社會 |
| `grade`、`semester` | ✔ | 年級（國中 7～9、高中 10～12）、學期（1／2） |
| `book` | ✔ | 冊次或課程，例：`國文1（必修）`、`選修物理II 力學二與熱學`、`數學3A` |
| `unit`、`unit_title` | ✔ | **必須是標準單元表裡的代號與名稱**（見第 5 節），不可自訂 |
| `type` | ✔ | 見第 2 節；只能用表中的值（不要寫 `single_choice`） |
| `difficulty` | ✔ | 1～5，見第 4.3 節 |
| `group_stem` | 題組 | 題組共用的短文／情境／說明；同組每題放一字不差的同一段；沒有題組寫 `null` |
| `stem` | ✔ | 題幹，寫法見第 3 節 |
| `options` | 選擇題 ✔ | **一律是清單** `[{"label":"A","content":"…"}]`，代號 A、B、C… 連續；非選擇題寫 `null` 或 `[]` |
| `answer` | ✔ | **一律是清單**（見第 2 節各題型的寫法） |
| `explanation` | ✔ | 解說，不可空白（第 4.2 節） |
| `pattern`、`pattern_name` | 有題型目錄的科目 ✔ | 題型代號（`T03`）與名稱，必須在該單元的題型目錄裡（第 5 節） |
| `scoring_rule` | 多選題 ✔ | 給分規則（第 4.4 節） |

同一個檔案裡**欄位型別要一致**：不要同時出現「選項有時是字典有時是清單」「答案有時是字串有時是陣列」。

## 2. 題型 `type` 與答案寫法

| type | 意義 | 選項 | `answer` 寫法 |
|---|---|---|---|
| `single` | 單選 | 國中**剛好 4 個**；高中 4 或 5 個（照原卷） | `["B"]`，只能一個字母 |
| `multiple` | 多選 | 2 個以上（高中常 5 個） | `["A","C","D"]`；題幹要標「（應選 N 項）」 |
| `tf` | 是非 | 無 | `["O"]` 或 `["X"]` |
| `fill` | 填充、國字注音、選填（學測劃記） | 無 | 每格一個元素 `["3","7"]`；可接受的別種寫法放同一格的備註，不要多放元素 |
| `calc` | 計算、非選擇 | 無 | 最終答案，含單位或格式要求 `["$\\frac{3}{4}$"]` |
| `essay` | 簡答、問答、申論 | 無 | 一個元素：`參考答案＋評分要點`（見 4.4） |
| `matching` | 配合題 | 共用選項放 `group_stem` | 依序一格一個 |

不要輸出：英文聽力題（沒有音檔）、需要看圖但沒有圖的題。

## 3. 文字寫法（每一題都要遵守）

| 要表達的 | 寫法 |
|---|---|
| 公式 | 行內 LaTeX，前後加 `$`：`$\frac{2}{3}$`、`$x^{2}$`、`$H_{2}O$`、`$\sqrt{5}$`、`$\overline{AB}$`、`$\angle A$`、`$\times$`、`$\leq$`；單位用 `\text{ }` |
| 一般數字與文字 | 不要包進 `$` |
| 其他符號 | 直接 Unicode：∵ ∴ ≒ ° ⊥ ∥ ○ ● △ ※ → |
| 畫線處 | `<u>畫線部分</u>`；雙底線 `<u class="dbl">…</u>` |
| 作答空格 | `＿＿＿` 或 `（　）`，不加 `<u>` |
| 表格 | Markdown 表格（含 `\| --- \|` 分隔列），放題幹或 `group_stem`，**不要放進選項** |
| 粗體 | `**字**` |
| 換行 | 照分行寫 |
| 錢的 `$` | 英文句子裡的 `$100` 不用跳脫（兩個 `$` 要成對或都是貨幣） |

規則：
- `$` 必須成對；括號 `(` `)` 必須成對。
- **題組材料放 `group_stem`**，不可以併進某題的題幹或選項。克漏字沒有題幹時 `stem` 寫「（克漏字第N格）」。
- 國字注音、注釋這類只有兩三個字的題：大題作答指示放 `group_stem`（例「一、國字注音」），單獨取用才看得懂。
- 選項只放選項本身，不要混入表格或下一題的材料。
- **題目要能獨立作答**：題幹不得出現「如圖」「下圖」「附圖」「承上題」，除非確實附了圖／有 `group_stem`。要用到圖的資訊，用文字或表格寫清楚。
- 考古題：照抄原卷，不改寫；看不清的字寫 `□`；原卷印錯字照抄並在 `review_note` 註明。自命題不適用這條。

## 4. 自命題（原創）的品質要求

### 4.1 選項與答案位置（最容易出問題）
- **答案位置要平均**：整批單選 A／B／C／D 各約 25%，每個單元內也要分散（不可同一字母佔多數）；多選的正確組合也要多樣。
- **干擾選項要「看起來合理但有一處錯」**：長度、語氣、結構和正確選項相近；錯在單一概念或條件上。
- **不要有可猜的線索**：正確選項不可特別長（超過其他選項平均 1.3 倍的比例要很低）；不要用「永遠、完全、一律、所有、絕對、只能」當錯誤標記；不要出現荒謬到不用讀題就能排除的選項。
- 單選只能有一個答案；多選每個選項要能獨立判斷對錯。

### 4.2 解說 `explanation`
- 先寫正確答案與依據（觀念、定義、推導或計算過程），再逐項說明錯誤選項錯在哪（多選題每個選項都要說明）。
- 解說裡出現的選項字母必須和 `answer` 一致。
- 計算題寫出關鍵算式與單位；史實、法條、數據要正確可查證，沒把握不要寫。

### 4.3 難度 `difficulty`
| 值 | 標準 |
|---|---|
| 1 | 單一觀念直接套用、記憶或一步計算 |
| 2 | 一般段考題：兩三個步驟，或需要判讀圖表 |
| 3 | 多步驟推理、條件較多，或需要轉換題意 |
| 4 | 跨單元綜合，或需要巧思 |
| 5 | 競賽或資優程度，少數學生能解 |

依題目本身判斷，**不要平均分配**，也不要依題型套用（選擇題可以是 5、計算題可以是 1）。

### 4.4 多選與簡答
- 多選題：題幹標明「（應選 N 項）」；`scoring_rule` 寫給分，例：`每題各選項獨立判定，全對得滿分，錯 1 個選項得 3/5 分，錯 2 個選項得 1/5 分，錯 3 個以上或未作答得 0 分`。
- 簡答／申論：`answer` 放「【參考答案】＋【評分要點】」，每個要點標配分與總分（例：`（2分）`、`滿分 6 分`），不要只寫一段整體作答。

### 4.5 版權與原創
- 題幹、選項、情境、解說都是原創；現代文學受版權保護的課文只測概念、修辭、手法，不貼原文段落；古文等公版文本可適度引用，引文必須正確。
- 題目不得與已有的考古題或同批其他題雷同（題幹完全相同視為重複）。

## 5. 單元與題型編碼

| 項目 | 規則 | 檔案 |
|---|---|---|
| 國中單元 | 年級→學期→科目→子科→版本→單元（國中：版本未標用翰林） | `data/export/taxonomy/curriculum.json` |
| 高中單元 | 代號如 `MA-1-1-1`、`PH-S1-2-3`、`BI-1-1-4`；名稱要和表完全一致 | `data/curriculum/senior.yaml` |
| 國中數學題型 | 鍵 `7-1_1-2:T03` | `data/export/taxonomy/math_patterns.json` |
| 高中題型 | 單元代號＋題型代號，例 `MA-1-2-1:T03`；每個單元的題型要盡量都出題 | `data/curriculum/senior_patterns/<科目>/*.yaml`；全表 `docs/PATTERN_CATALOG_ALL.csv` |

- 單元、題型**只能選表裡有的**；表裡沒有就在回報裡提出，不要自行新增代號。
- 還沒有題型目錄的科目（高中歷史、地理、公民與社會、國文；國中非數學）`pattern` 欄可省略。

## 6. 會被品管剔除的情況

- 題幹空白或太短（字詞題有大題說明、題組有短文的除外）
- `single` 選項數不符；`tf` 有選項但不是 2 個
- 選項代號重複，或某選項沒有內容也沒有圖
- `$` 沒成對、括號沒成對
- 答案欄位空白；選擇題的答案不在選項代號裡；答案寫「送分」「待確認」
- 引用不存在的附圖或 key

## 7. 修正題交件格式（修補有問題的題）

每批一個 `REVISED_<批次名>.jsonl`，每題一行，**每題都要交**：

```json
{"id": "…", "result": "fixed", "type": "single", "stem": "…", "group_stem": null,
 "options": [{"label":"A","content":"…"}, …], "answer": ["B"], "explanation": "…", "fix_note": "補上四個選項；答案由題幹算出"}
{"id": "…", "result": "unfixable", "unfixable_reason": "題目重點是看圖，無法用文字重現"}
```

- `fixed` 要有 `type`、`stem`、`options`（選擇題）、`answer`、`fix_note`；只改有問題的地方，題目考的觀念與難度不變。
- 沒把握就標 `unfixable`（會暫緩不上站），不要硬補。選項若有附圖，選項代號與數量不可改。
- 詳細見 `docs/JUNIOR_FIX_HANDOFF.md`。

## 8. 交件前自我檢查清單

1. 每題欄位齊全，型別一致（`options` 清單、`answer` 清單、`type` 在表內）。
2. 單元代號、名稱與標準表一致；題型在該單元目錄裡。
3. 選擇題答案字母都在選項內；單選只有一個答案。
4. 整批答案位置各約 25%、單元內分散；沒有「最長選項即答案」傾向；沒有絕對詞當錯誤標記。
5. 每題有解說；多選有「應選 N 項」與 `scoring_rule`；簡答有評分要點。
6. `$`、括號成對；沒有「如圖」「承上題」卻沒有圖或題組。
7. 沒有重複題幹。
8. 考古題 YAML：`python scripts/check_bank_yaml.py <bank 資料夾> --assets <附圖資料夾> --existing`；修正題：`python scripts/junior_fix_check.py <任務檔> <交件檔>`。
9. 交 `REPORT_<批次名>.md`：題數、各題型與難度分布、答案位置分布、自檢結果、有疑慮的題。
