# 高中自命題（ROUND6 第一冊）驗收回饋

驗收對象：`ORIG_{國文,歷史,地理,公民與社會,英語}_第一冊.jsonl`，共 440 題（每單元 5 題，88 個單元）。

## 結論
內容抽樣大致正確、格式乾淨，但**現在不能直接入庫**。有下列必須修正的問題；修完才收。

## 一、必須修正
1. **答案位置嚴重偏斜**（單選 301 題）：A 58%、B 31%、C 8%、D 3%。國文 132 題單選有 **129 題答案是 A**。學生不看題目全選 A 就能過半。
   → 每科單選的 A/B/C/D 要大致各 25%（同一單元內也要分散）；多選的正確選項組合也要多樣。
2. **答案有線索可猜**：
   - 答案選項長度是其他選項平均的 1.3 倍以上，佔 53%，最長的選項就是答案的佔 74%。
   - 「永遠、完全、一律、所有、絕對…」這類絕對詞出現在 12.8% 的干擾選項，答案選項只有 1%。
   - 干擾選項過於荒謬（例如「規定慢性病患每次領藥必須重新住院七天檢查」「大腦退化」），不用讀題就能排除。
   → 干擾選項要寫成「看起來合理但有誤」：長度相近、語氣相近、錯在單一概念上；避免絕對詞當作錯誤標記。
3. **難度是機械分配的**：每單元固定 1～5 級各一題，不是真的難度。難度 4、5 的題實際上因為上述線索並不難。
   → 難度請依解題步驟、概念層次判定，不要平均分配；寧可某單元沒有 5 級題。
4. **英語單元不在標準單元表**：`EN-1-x-1` 共 10 個單元，高中單元表（`data/curriculum/senior.yaml`）沒有英文科。單元名稱還是特定版本課文標題（例如 Firsts in Life、Goodbye, John）。
   → 英文先不交，等題庫端建好英文單元表再依表出題。
5. **多選題只有 16/70 題在題幹標明應選幾項**，其餘寫「哪些」；請全部統一格式（要嘛都標、要嘛都不標），並說明給分方式。

## 二、其他
- 簡答題（essay，47 題）答案是整段參考作答，沒有評分重點（給分標準）。請改成「參考答案＋評分要點（每點幾分）」。
- 引用現代文學課文僅作概念測驗，這個作法 OK；題幹引用的古文請確認引文正確。
- 每單元固定 5 題不夠；補題時以題型目錄（`data/curriculum/senior_patterns`）為準，各單元的題型要覆蓋。
