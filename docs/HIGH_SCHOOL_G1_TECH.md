# 督察技術支援 #005：G1 解析器卡關的原因與解法（2026-11-11 16:00）

**發布者：OLE-QS 題庫端督察 agent。給監工轉 Codex、worker-agent-phoenix-01。**
這是技術支援，不是派工；怎麼排工仍由監工決定。G1 驗收標準不變。

## 1. 卡關的原因

翰林、南一版 .doc 的題號、選項代號 (A)～(E)、加括號代號 (甲)、「第 22.、23. 題為題組」都是 Word 的 **EQ 欄位**。

LibreOffice 把 .doc 轉成 .docx 或 PDF 時，會把 EQ 欄位換成空白的 FILLIN，這些字全部消失。可是底線、表格、圖片又只有 .docx 讀得到。
所以 C1 解析器只能拿 .doc 原始文字和 .docx 硬拼，結果是：

- 底線對不回原位（0/5）；
- 選項混入（Pilot-2 有 44 題）；
- 題組範圍抓不到。

國文第 1 批出現的「底線全域取代」「選項跨題汙染」也是同一個原因。

**另外發現：** 之前大家用的原卷 PDF 也是 LibreOffice 直接轉的，**同樣沒有題號和選項代號**，例如興大附中數學第 1 頁只剩「（　）設 f(x)…」和沒有 (A)～(E) 的五行選項。

## 2. 解法：先改寫 .doc，再轉檔，之後只讀 .docx

交接包新增兩支工具，都只用標準函式庫：

```bash
# 1. 把 EQ 欄位就地換成它顯示的文字（原檔不動，輸出到 work/）
python scripts/flatten_doc_eq.py --dir 原始Word資料夾 work
# 2. 轉 .docx 和原卷 PDF（PDF 一律用這份，sources/ 也放這份）
soffice --headless --convert-to docx --outdir work work/*.doc
soffice --headless --convert-to pdf  --outdir work work/*.doc
# 3. 讀成段落流，規則 A、B、E、上下標、表格、附圖位置都已處理好
python scripts/docx_stream.py work/卷.docx > work/卷.jsonl
```

- `flatten_doc_eq.py` 做兩件事：
  - 把每個 EQ 欄位改寫成它顯示的文字：
    - 題號是 `12.`，代號是 `（甲）`、`（A）`，題組標題照原字，圈字是 `③`；巢狀欄位也處理。
    - 分數 `\f`、根號 `\r`、上下標 `\s` 這類公式欄位原樣保留成 `⟦EQ …⟧`，由 `docx_stream.py` 轉成 `$LaTeX$`。
  - 把 .doc 的主文與文字方塊欄位表長度設成 0，讓 LibreOffice 照字面讀。

  檔案長度不變，所以底線、字型、圖片位置都留在原處。
- `docx_stream.py` 每段輸出一行 JSON：`{"i", "kind": "p"|"table", "text", "images"}`。
  - `text` 已經是 `(甲)`、`(A)`、`<u>…</u>`、`x^{2}`、`[圖1]`、Markdown 表格。
  - `images` 是 `word/media/…` 檔名。
  - 文字方塊（圖上的標註）不輸出。
  - 轉不了的 EQ 指令照原樣留著，檢查程式會以「Word欄位碼」攔下。請補進 `docx_stream.py`，不要手改 YAML。
- MathType 方程式（EMBED Equation）在新 .docx 裡會變成文中的預覽圖，位置正確。
  - 要用 MTEF 程式轉 LaTeX 的話，到**原檔**轉出的 .docx 取 `word/embeddings/oleObject*.bin`。
  - 第 k 個方程式圖對應第 k 個 OLE 物件。

## 4. 解析器還要自己做的部分（不准手改，照第 1.2 節）

1. **切題**：題號段落是 `^(\[圖\d+\])*（\s*）\d+\.`。數學填充、非選題號格式不同，要另外認。
2. **題組**：`第\s*N.[、～]\s*M.\s*題為題組` 開始，下一個題組標題或大題標題結束。題組材料放 `group_stem`，同組每題都要有。
3. **選項**：`(A)`～`(E)` 出現在同一段或後續段落都要能切；表格裡的 (A)～(D) 是表頭，不是選項（Pilot-1 第 1 題）。
4. **答案**：以 `《答案》`、`參考答案`、`試題答案` 之後的 `N.(X)` 為準，規則 C、D 照舊。
5. **附圖**：
   - 用 PyMuPDF 在新 PDF 找圖片位置（`page.get_image_info(xrefs=True)` 的 bbox），再用 `crop_figure.py --rect` 裁圖；
   - 依 `[圖n]` 所在的題掛圖；
   - 數學卷的方程式預覽圖是文中的小圖，不是附圖，要轉成 LaTeX，不要掛成 `figures`。
6. **自驗**：照督察授權書第 3 節（檢查程式 3.1、`round3_qa.py --batch`、人工抽 10 題）。
