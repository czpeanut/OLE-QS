## 2. 三個會讓題目直接報廢的發現

### 🔴 發現 1：抽取內嵌影像會毀掉圖片（透明度遺失）

第一次用最直覺的作法 —— PyMuPDF 的 `Pixmap(doc, xref)` 把內嵌影像抽出來 —— 結果：

```
p1 xref=21  SMask=22      ← 每一張圖都帶 SMask（軟遮罩／alpha）
p2 xref=43  SMask=44
p3 xref=55  SMask=56  ...
```

**14 張圖全部帶 SMask，抽出時遮罩被丟棄，原本透明的區域變成純黑。**
其中 `圖(八)`（燒杯半透膜）與 `圖(九)`（長條圖）**整張變全黑，完全不可用** —— 而這兩張圖是第 28、29 題的作答依據，圖毀了題就報廢。

### 🔴 發現 2：同一張圖會被重複放置，照 xref 抽只會拿到一張

```
p2 xref=49  放置 4 次
```

第 23 題的四個選項圖，在 PDF 裡是**同一個影像物件旋轉／翻轉後擺了四次**。
`get_images()` 依 xref 去重，所以照 xref 抽只會得到 1 張，**少掉 3 個選項**。

### ✅ 兩個問題的共同解法：渲染頁面區域，不要抽物件

```python
# 錯誤：抽出內嵌物件 —— 丟失透明度、丟失重複放置
pix = pymupdf.Pixmap(doc, xref)

# 正確：用 get_image_rects() 拿到「每一次放置」的座標，再從頁面渲染該區域
for rect in page.get_image_rects(xref):
    page.get_pixmap(dpi=300, clip=rect).save(...)
```

渲染出來的就是讀者看到的樣子，透明度已正確合成，重複放置也各自成為獨立檔案。
**抽取數 14 張 → 渲染數 17 張**，缺的 3 張正是第 23 題的選項圖。

順帶一提：原生數位 PDF 的圖形座標可以**直接從 PDF 讀出**，
完全不需要版面偵測模型（DocLayout-YOLO / PP-Structure）。開發計畫裡那一整塊可以省掉 —— 但只限原生數位這條路線。

## 3. 兩種必須支援的結構（數學卷完全沒出現）

### 多題共用一張圖

```
圖(一) 顯微鏡  → 題 1、2、3、4、5
圖(二) 四種細胞 → 題 6、7、8、9、10
圖(三) 五支試管 → 題 11、12、13
閱讀短文        → 題 34、35
```

**13 題（佔全卷 37%）依賴共用素材。** 若逐題獨立擷取，這些題目會全部失去圖而無法作答 ——
而且**逐題檢查完全看不出異常**：題幹完整、選項齊全、配分正確，只是永遠答不出來。

已在資料格式加入 `shared_assets` / `passages` 區塊與 `used_by` 反向宣告，
驗證器會比對「宣告的使用者」與「實際引用的題目」是否一致。

### 選項本身就是圖

第 23 題的四個選項沒有任何文字，就是四張視野圖。
純文字擷取會讓四個選項全變成空字串 —— 同樣地，題幹完整、選項數正確（4 個），**傳統結構檢查抓不到**。

驗證器已加入「選項需有文字**或**圖片」的檢查。

## 4. 對驗證器的修正：題號慣例因卷而異

| 卷 | 編號方式 |
|---|---|
| 數學卷（PoC #001） | 分大題各自重編：`1..10` / `1..15` / `1..4` |
| 自然科卷（PoC #002） | **全卷連續**：填充 `1~13` / 選擇 `14~33` / 題組 `34~35` |

**兩種都存在，寫死任何一種都會整卷誤報。** PoC #001 的驗證器只支援前者，
套到這份卷會把選擇題 `14~33` 判成「應為 1~20」而全數報錯。

已改為自動判斷（各大題是否都從 1 開始），並可用 `document.numbering` 明確覆寫。
全卷連續時，額外檢查各大題的題號範圍不得交錯。

## 5. 文字圖層的品質與需要的正規化

文字圖層的正確率**遠高於 OCR**，但有兩個固定型態的雜訊：

| 原始 | 應為 | 說明 |
|---|---|---|
| `113 學年度第1 學期` | `113學年度第1學期` | 中文與半形數字之間被插入多餘空白 |
| `37 ﾟC` | `37 °C` | 度數符號被編碼成**半形片假名濁音符**（U+FF9F） |

兩者都是規則可解的，不需要模型。但若不處理，會影響全文檢索與去重比對。

另外，第 29 題題幹含一個**分子分母都是中文長句的分數式**：

$$\frac{\text{該組飼料飼養的乳牛分泌的平均乳汁量}}{\text{一般飼料飼養的乳牛分泌的平均乳汁量}} \times 100\%$$

文字圖層會把它壓成一行，失去分數結構。**這類版面語意仍必須靠影像判讀補回** ——
也就是說，原生數位 PDF 不是「完全不需要看圖」，而是「看圖的範圍小很多」。

## 7. 分類：這份卷沒有範圍註記

PoC #001 的重大發現是「段考卷會印考試範圍，可用來大幅縮小分類候選集合」。
**但這份自然科卷沒有印範圍。**

→ 範圍註記是**加分項而非可依賴的前提**。分類流程必須在沒有它的情況下也能運作：
有範圍註記時縮小候選集合，沒有時退回「該科目全部候選節點」。

另註：本份的課綱代碼（`Da-IV-1`、`Ma-IV-1`、`Mb-IV-1` 等）為推估值，
與 PoC #001 相同，仍待 P4 匯入教育部正式條目後全面覆核。

## 8. 結論

**原生數位 PDF 這條路線比預期更划算**：文字無損、圖形座標免費、不需要版面偵測模型。
如果你那批考古題多數是這種格式（校內段考卷通常是），整體成本與正確率會遠優於原本以掃描件為前提的估算。

**但風險轉移了**：從「文字辨識錯誤」轉到「**結構性遺漏**」——
共用圖沒帶到、選項圖沒抓到、圖片透明度毀損。這三類錯誤的共同特徵是
**題目表面上完全正常，只是答不出來**，人工快速掃過也未必看得出來。

這正好強化了 PoC #001 的結論：結構驗證與人工校對台不是加分項，是必要條件。
本次已針對這三類錯誤各補上一道自動檢查，並以注入故障測試確認全部會觸發。
