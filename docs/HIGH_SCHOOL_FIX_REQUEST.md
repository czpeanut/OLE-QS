### 3.1 缺圖（3,605 題）

題目寫「下圖、如圖、附圖、圖(一)、照片」，但這題沒有 `assets`、`shared_asset` 或選項圖，**學生無法作答**。

> `doc_111_台中_台中二中_社會_地理_g10s1e1_s1_5`：「下圖為臺灣某高鐵車站及其周邊地區遙測衛星影像圖，照片是圖中某地的實景照片。請問照片最可能位於圖中何處？」——沒有圖。

地理一半的題目是這種情況。原因是解析 Word 時沒有取出內嵌圖片（`w:drawing`、`v:imagedata`、WMF／EMF）。修法見第 4.4 節。

### 3.2 缺表與選項混入（1,044＋1,046 題，同一個原因）

Word 表格（`w:tbl`）被攤平成一行一格的文字，接在**最後一個選項**後面；題幹寫「下表」，但表格不見了。

> `doc_111_屏東_屏東高中_社會_地理_g10s1e2_s1_1`：題幹「下表關於向量與網格模式之應用狀況，何者最適合？」，
> 選項 D 變成 `影像處理\n向量模式\nˇ\n網格模式\nˇ\nˇ\nˇ`（表格內容）。
>
> `doc_111_台中_台中二中_社會_地理_g11s1e3_s1_9`：選項 D 是「甲丙丁。（資料來源：國際貨幣基金…）\n（單位：十億美金）\n國際貨幣基金\n世界銀行…」。

另一種是**下一題的閱讀材料併進這一題的最後一個選項**，下一題就只剩「由上述新聞中…」：

> `doc_111_台北_明倫_社會_公民與社會_選修公民與社會II_g12s2e1`：
> - 第 23 題最後一個選項的結尾接了一整段習近平的新聞稿，那其實是第 24～25 題的題組材料。
>   第 24 題「題意中，底線的部分…」、第 25 題「由上述新聞中…」都沒有 `group_stem`。
> - 第 25 題最後一個選項又接了第 26 題的太陽花學運判決新聞。

修法：表格轉成 Markdown 表格放進**該題題幹**（或題組的 `group_stem`）；選項只留選項本身。見第 4.3 節。

### 3.3 題組材料遺失（103 題）

題幹一開頭就寫「根據上文／由上述…」，卻沒有 `group_stem`。材料通常在前一題的最後一個選項裡（第 3.2 節），或整段遺失。

> `doc_109_高雄_鼓山_社會_公民與社會_g11s1e2_s2_45`：「根據上文內容判斷，下列敘述何者正確？」——沒有任何材料。
> `doc_112_高雄_新莊_自然_地科_g10s1e2_s1_1`：「根據上述氣壓隨高度的變化資料中…」——第 1 題，前面沒有資料。

題組材料要放進同組**每一題**的 `group_stem`（一字不差），不可以只放第一題。

### 3.4 上下標遺失（數理卷，30 題，但影響所有未交的數理卷）

用 MathType 打的公式轉 LaTeX 沒問題，例如 `$\frac{Gm_{1}m_{2}}{r^{2}}$`。但 **Word 一般文字設成上標、下標的字**（`w:vertAlign`）被攤平，數值直接錯：

| 題目 | 交來的 | 應為 |
|---|---|---|
| `doc_113_台中_興大附中_數學_g10s1e2_s1_1` | 除以x2－1的餘式 | 除以 $x^{2}-1$ 的餘式 |
| `doc_113_台中_興大附中_數學_g10s1e2_s1_2` | 20245－8．20244－79．20242－17．2024－10 | $2024^{5}-8\cdot 2024^{4}-\dots$ |
| `doc_108_台北_永春_自然_物理_g10s1e1_s1_3` | 2.0×103、公斤／公尺3 | $2.0\times10^{3}$、公斤／公尺 $^{3}$ |
| `doc_112_台北_景美女中_自然_化學_選修化學V_g12s2e2_s3_30` | C4H10O | $C_{4}H_{10}O$ |

修法見第 4.2 節。**數理三科補交前一定要先修好這一點。**

## 4. 修正方法：重新解析 Word 原檔

上面的問題幾乎都出在「把 Word 當純文字讀」。原檔都還在雲端，請照下面的方式重新解析，**不需要用模型重打題目**。

### 4.1 先統一轉檔

```bash
soffice --headless --convert-to docx 原檔.doc      # .doc → .docx，給程式解析
soffice --headless --convert-to pdf  原檔.doc      # → PDF，交到 sources/，也用來找附圖的 crop
```

### 4.2 依 XML 順序走過 body，保留上下標

- 依 `document.xml` 的 `w:body` 子元素順序同時處理段落 `w:p` 與表格 `w:tbl`（不要先讀完所有段落再讀表格）。
- 每個 run（`w:r`）檢查 `w:rPr/w:vertAlign`：
  - `superscript` 寫成 `^{…}`，`subscript` 寫成 `_{…}`；
  - 連同前面的底數一起包進 `$…$`，例：`$x^{2}-1$`、`$10^{3}$`、`$C_{4}H_{10}O$`。
- MathType／OMML 方程式照你們現在的方式轉 LaTeX（這部分是對的）。
- 符號字型（`w:sym`、Symbol／Wingdings、PUA 字元）要對照轉換，答案代號尤其要注意（第 3.6 節）。

### 4.3 表格與題組

- 題號之間遇到的 `w:tbl` 屬於**目前這一題**（或目前題組）。轉成 Markdown 表格，放在題幹（或 `group_stem`）裡，
  位置照原卷，通常接在「下表…」那句後面。
- 只有合併儲存格複雜、或表格裡有圖的，才改用截圖（`kind: table`）。
- 選項的範圍是「(A) 到下一個選項代號，或到下一題題號／大題標題／題組說明為止」。表格和段落都不能併進選項。
- 題組範圍以「第 X～Y 題為題組」「閱讀下文，回答第 X～Y 題」這類標示為準：
  標示之後、第 X 題題號之前的段落、表格、圖都是共用材料。

### 4.4 附圖：從原檔取圖，再到 PDF 找位置

1. 走 body 時遇到圖（`w:drawing`、`v:imagedata`、`w:object`）就記下「目前題號」或「目前題組」，
   決定它屬於哪一題的 `assets`、哪個選項的 `asset`，或是題組的 `shared_assets`。
2. 圖檔照規格命名（第 3.5 節），WMF／EMF 轉成 PNG（LibreOffice 或 Inkscape），寬度至少 300 像素。
3. `crop`：用 4.1 轉出的 PDF，以 PyMuPDF `page.get_image_info(xrefs=True)` 或 `page.get_image_rects(xref)`
   找到那張圖在第幾頁、哪個框，寫進 `crop: {page, rect}`。
   WMF／EMF 這類向量圖在 PDF 裡不是點陣圖，找不到 image 框：
   - 改用該頁的向量繪圖範圍（`page.get_drawings()` 合併相鄰的框）定位；
   - 或用工具包的 `scripts/crop_figure.py` 直接從 PDF 裁，它會印出 crop。
4. **公式物件（MathType）不是附圖**，不要當成圖交。

## 5. 交件與驗收標準

```bash
python scripts/check_bank_yaml.py high_school/bank --assets high_school/assets --existing --strict \
  --issues-csv high_school/剩餘問題.csv
```

- **結束碼必須是 0。** `--strict` 會把內容問題（◇）也算成錯誤。
- 真的是誤判、無法再修的題目，從 `剩餘問題.csv` 挑出來，寫進 `manifest.json` 該卷 `notes`（題號＋原因）。
  例如「原卷本來就沒有附圖」「原卷破損」。
- 回報數字以「實際交出的檔案」為準，不要以任務狀態欄計算。
- 每次交件附上：
  1. `bank/`（全部 YAML）；
  2. `assets/`（全部 PNG，只放有被 YAML 引用的圖）；
  3. `sources/`、`answers/`（PDF）；
  4. `manifest.json`；
  5. 新版檢查程式的完整輸出（文字檔）。
- 交件順序建議：
  1. 先修正已交的 606 份（文史地公生地科國文）；
  2. 再用修正後的解析方式處理數理三科。

題庫這邊收到後會再抽卷對照原檔，抽查不合格的整批退回。
