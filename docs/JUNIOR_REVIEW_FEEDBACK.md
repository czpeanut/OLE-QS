# 國中逐題審題：驗收回饋（請 agent 調整審題方式）

驗收對象：REVIEW_*.jsonl（81 批、85,540 題）。**整體品質高、可採用**（抽樣：改答案約 37/40 正確、「同意原答案」23/23 正確、有圖題讀得懂）。
下列問題修正後，才會寫回題庫。逐題 id 清單：`docs/junior_review_feedback_ids.csv`（欄「問題類別」對應下面編號）。

## A. 沒有選項的選擇題（最重要）
- **A1**：39 題資料庫裡沒有選項，卻標 `text: ok`。**沒有選項的選擇題一律標 `text: issue`**（text_issue 寫「缺選項」），不可標 ok。
- **A2**：222 題沒有選項卻給了 `answer: fix` 與 `answer_fix`。沒有選項就無從判斷字母，**不要給答案**（`answer: none`）。
- 做法：審每題前先確認 `type` 為 single／multiple 時，選項至少 2 個且 label 連續（A、B、C…）。

## B. 答案欄位格式
- **B1**（1 題）：選擇題的 `answer_fix` 必須是選項字母（如 `["C"]`），不可填內容（例：`\frac{11}{16}`）。若選項內容與題目不符，標 `text: issue`。
- **B2**（4 題）：`type: single` 的 `answer_fix` 只能一個字母。若認為有兩個答案，表示題目有問題（或應是複選），請標 `text: issue` 並在 note 說明，不要硬給兩個。
- **C**（16 題）：原本沒有答案、卻標 `answer: agree`。沒有原答案時不能「同意」，請改為 `fix`（給出答案）或 `none`。

## C. 答案判斷的錯誤（法律／專業知識題要查依據）
- 「褫奪公權」該題：agent 答 C，但依刑法第 36 條應為 A。抽樣 40 題改答案有 1 題明確錯誤，集中在法律、時事等需要精確條文的題。
- 要求：**法律、制度、年代、專有名詞類的題，改答案時 `answer_reason` 必須寫出依據（條文／史實／定義）**；沒有把握就標 `unsure`，不要硬改。

## D. 單元修正（unit_fix）格式不一致
目前三種格式混用，無法機器讀取：
- **D1**（46 題）：`unit_fix` 是物件（dict，含 publisher／code 等），應統一為字串。
- **D2**（2,609 題）：字串夾帶單元名稱（例：`2-1 憲法保障的基本權利`）。**`unit_fix` 只放代號**（例：`2-1`），名稱不要放；版本放 `unit_fix_book`。
- **D3**（522 題）：`unit: fix` 但代號和原單元相同（等於沒修）。請改標 `unit: ok`；寫入前先比對原單元。
- 自然、社會有子科（物理／化學／生物／地科；歷史／地理／公民），**同一個代號可能出現在不同子科**。`unit_fix` 若屬於不同子科，必須另外填 `unit_fix_sub`（子科名）。目前約 233 題無法判斷屬於哪個子科。
- 數學 `pattern_fix` 維持 `"7-1_1-2:T03"` 或 `":NEW:名稱"`。

## E. 其他
- `text: issue`（2,688 題）請在 `text_issue` 寫明問題類型（缺選項／缺圖／亂碼／答案卷錯位／題幹不完整），方便分流處理。
- 數學中被標記不確定的題，請寫出你的計算結果，不要只寫 unsure。

## G. 驗收會自動檢查（交件前請自行跑 `junior_review_tool.py check`）
1. 選擇題必有選項；`answer_fix` 字母必在選項內；單選只能一個字母。
2. 無原答案不得 `agree`。
3. `unit_fix` 為純代號字串，且不同於原單元。
4. `text: issue` 必附 `text_issue`；`answer: fix` 必附 `answer_reason`。
