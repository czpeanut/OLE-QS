## 1. 這一輪要做什麼：從原始 Word 檔全部重做

### 1.1 起點

- **只用原始檔**：雲端「校名來源題庫集中庫」各科資料夾裡的 `.doc`／`.docx`（任務清單 `rel_path`）。

### 1.2 解析方式（用程式解析 Word，不要用模型重打題目）

`.doc` 先用 `scripts/flatten_doc_eq.py` 改寫 EQ 欄位，再用 `soffice --headless --convert-to docx` 轉成 `.docx`，並用**改寫後的 .doc** 轉一份 PDF 放 `sources/`（裁示 #005：不改寫的話，LibreOffice 會把題號、選項代號、(甲) 全部吃掉，PDF 也一樣）。
`scripts/docx_stream.py` 已經把下表大部分的轉換做好，解析器可以直接從它的輸出切題。
然後依 `word/document.xml` 的 `w:body` **子元素順序**走過一遍，段落 `w:p` 與表格 `w:tbl` 一起處理：

| Word 裡的東西 | 輸出 |
|---|---|
| 題號（`1.`、`(　)1.`、自動編號 `w:numPr`）、大題標題 | 切題、`sections` |
| 選項 `(A)…(E)`（含同一行多個選項、跨行選項） | `options`；選項到下一個選項代號、或下一題／大題／題組說明為止 |
| 「第 X～Y 題為題組」「閱讀下文，回答第 X～Y 題」之後到第 X 題之前的段落、表格、圖 | 同組**每一題**的 `group_stem`（一字不差）＋ `shared_assets` |
| 表格 `w:tbl` | 照原卷的列與欄轉 Markdown 表格，放在所屬題目（或題組）的題幹裡；合併儲存格太複雜的，裁成圖（`kind: table`，要有 crop） |
| `w:vertAlign` 上標／下標 | 連同底數包進 `$…$`：`$x^{2}-1$`、`$2.0\times10^{3}$`、`$C_{4}H_{10}O$` |
| MathType 物件（`Equation.3`、`Equation.DSMT4`，OLE 內的 MTEF） | 轉 LaTeX |
| Office 方程式（`m:oMath`，OMML） | 轉 LaTeX |
| EQ 欄位（`w:fldSimple` 或 `w:fldChar` 包起來的 `EQ …`） | 依指令轉換，見下表 |
| 圖（`w:drawing`、`v:imagedata`、`w:pict`；WMF／EMF） | 附圖，見 1.4 |
| 符號字型（`w:sym`、Symbol／Wingdings 字型、U+F000～F0FF） | 轉成對應的 Unicode 字；答案代號見 1.5 |
| 卷末「參考答案」「試題解析」「《答案》」 | 答案與詳解；不得混進題目 |

**EQ 欄位常見指令**：

| 欄位 | 輸出 |
|---|---|
| `\f(a,b)` | `$\frac{a}{b}$` |
| `\r(x)`、`\r(n,x)` | `$\sqrt{x}$`、`$\sqrt[n]{x}$` |
| `\s\up(k)(x)`、`\s\do(k)(x)` | `^{x}`、`_{x}` |
| `\o\ac(○,1)` 這類圈字 | 對應的 ① 等字 |
| `\o\al(　,1.)` 這類只是題號排版 | 只留題號 |
| `\x(…)`、`\b(…)` | 框線、括號，照意思輸出 |

**輸出裡不得留下任何欄位碼或控制字元**（`EMBED`、`EQ \`、`\o\al`、`MERGEFORMAT`、`\x01`、`\x13`～`\x15`）。

**試做卷驗收後追加的規則**（裁示 #002，全量一律套用）：

| 規則 | 內容 | 試做卷的錯誤例子 |
|---|---|---|
| A. 括號代號保留括號 | `EQ \o(　,\l((　)),甲)` 這類加括號的代號一律輸出 `(甲)`、`(乙)`、`(二)`…，題幹、題組、選項都一樣；選項代號 (A)～(E) 照原規則轉成 `options` 的 label。**每份卷交件前核對**：原卷題目區這類欄位的個數＝YAML 括號代號的個數（題組材料每組只算一次），結果寫在 QA_NOTES.md（裁示 #003） | 「資料有：甲道路圖乙空照圖」應為「(甲)道路圖(乙)空照圖」；「圖(二)臺灣西南部…」掉了「(二)」；明倫公民題組漏了「(甲)」標記 |
| B. 底線轉 `<u>` | `w:u` 不是 none 且內容不是空白的 run，輸出 `<u>…</u>`；空白底線（作答格）寫成 `＿＿＿`，不加 `<u>` | 屏東地理第 4、6 題的畫線處沒標，第 6 題問的就是「(乙)劃線部分」 |
| C. 答案區題號兩種都要認 | 答案區的題號同時認 EQ 欄位與純文字題號；解析完逐題與題數比對 | 屏東地理第 16 題題號是純文字，(D) 被併到第 15 題，答案變成 [A, D] |
| E. 段落內折行併回一行 | 原卷排版造成的折行併回同一行；只有原卷真的分段或分項才換行 | 永春物理「2⏎nm」「2⏎e／3」 |

**公式真的轉不出來的題目，整題不要交**：從 YAML 刪掉，在 `manifest.json` 該卷的 `dropped` 列出題號與原因。
一份卷刪掉超過 10% 題目的，整卷不交，列進 `skipped`。**不准用截圖、占位字或刪掉公式湊過檢查。**

### 1.3 文字

- 照抄原卷，**不得刪除、改寫、摘要**任何題目文字。看不清楚的字寫 `□`。
- 原卷題目區的文字要**完整**出現在 YAML。新版檢查會算覆蓋率，低於 90% 算錯誤。

### 1.4 附圖

1. **對題靠位置，不靠順序**：走 body 時遇到圖，就記下當下所在的題號（或題組、選項），決定它屬於哪一題的 `assets`、哪個選項的 `asset`、或題組的 `shared_assets`。
2. 一張圖只屬於一個地方；同一個題組共用的圖放 `shared_assets`，不要複製到每一題。
3. **每張圖都要有 `crop`**，指向 `sources/` 裡那份 PDF 上的實際位置（PDF point，原點左上角）：
   - 點陣圖可以用 PyMuPDF `page.get_image_rects(xref)` 找位置；
   - 向量圖（WMF／EMF）用 `page.get_drawings()` 的範圍，或用 `scripts/crop_figure.py` 裁。
   - **最簡單的做法是 PNG 直接用 `crop_figure.py` 從 PDF 裁**，crop 就一定對得上。
   - 新版檢查會照 crop 從 PDF 重裁、和 PNG 比對，對不上算錯誤。
4. 附圖要是**圖**：卷面文字、作答說明、空白區塊都不是附圖。寬至少 300 像素（200 DPI 以上）。
5. 檔名照規格：`s{大題}_{題號}_f{n}.png`、`s{大題}_{題號}_opt{A-E}.png`、`g{大題}_{第一題}_{最後一題}_f{n}.png`。

### 1.5 答案

- 只照原卷附的答案填，`answer_status: verified`、`answer_source: answer_key`。
  - 南一版：卷末「參考答案」。
  - 翰林版：「《答案》」區塊。答案代號是符號字型，要轉回 A～E：
    - 先確認 `w:sym` 的 `w:font`、`w:char`；
    - 常見 `F041`～`F045` 對應 A～E，但**每種字型都要用實際卷子核對**，不要假設。
- 「送分」「(B)(C) 皆給分」「(A)或(B)」：`answer` 列出可接受的答案，**`review_note` 一定要註明**，例如 `解答卷：(A)或(B)皆給分`、`解答卷：本題送分`（裁示 #002 規則 D）。
- 原檔沒有答案的卷，`manifest.json` 該卷 `has_answer_key: false`。**不准讓模型猜答案。**

### 1.6 禁止事項（發現任何一項，該科整批退回）

1. 用占位字（「詳見原卷」「圖略」「表略」）或空表格、假表格應付缺圖、缺表。
2. 刪除原卷文字，或把別題的文字貼過來充當題組材料。
3. 為了避開檢查而改寫題目用字（例如把「下圖」改掉）。
4. 依圖片順序分配附圖，或把同一張圖掛到多題。
5. 把卷面文字截圖、空白圖當附圖。
6. 讓模型猜答案填進 `answer`。
7. 修改 `check_bank_yaml.py` 或 `apps/api/quality.py`，或用其他版本的檢查程式回報結果。
8. 回報的數字和實際交出的檔案不符。
9. `sources/`、`answers/` 交的不是原檔轉出的 PDF（例如用 YAML 重新排版產生的 PDF）。
   - 原卷 PDF 必須由原始 Word 檔以 LibreOffice 或 Word 直接轉出。
   - 原始檔本來就是掃描影像的，交原始影像合成的 PDF。

### 3.2 自我檢查（必須通過）

```bash
python scripts/check_bank_yaml.py high_school/bank --assets high_school/assets \
  --sources high_school/sources --existing --strict --issues-csv high_school/剩餘問題.csv \
  > high_school/check_report.txt
```

- **結束碼必須是 0。** `--strict` 會把下列內容問題全部算成錯誤：
  - 缺圖、缺表、選項混入、題組材料遺失、上下標遺失、題幹混入解答、圖檔沒被引用；
  - 第三版新增：占位文字、Word 欄位碼、表格可疑、附圖沒有 crop、附圖頁碼不符、同圖多掛、附圖空白或過小、crop 與圖檔不符、原卷文字遺漏。
- 檢查程式真的誤判、而原文不能改的（督察裁示 2026-11-11）：**登記在 `manifest.json` 最上層的 `waivers`**，不要改原文。

  ```json
  "waivers": [
    {"id": "doc_108_台北_永春_自然_物理_g10s1e1_s1_7", "category": "缺圖",
     "reason": "「數位照片的檔案大小」是描述檔案容量，題目不需要附圖"}
  ]
  ```

  - `id` 是 `剩餘問題.csv` 第一欄，`category` 是第二欄，`reason` 至少 10 個字。
  - 登記的項目不計入 `--strict`，但會逐條列在 `check_report.txt` 給督察確認。
  - 理由不成立的，視同違反禁止事項 3。
  - 登記了卻對不到檢查結果、或理由太短，算錯誤。
- 第 3.1 版檢查程式（2026-11-11）：
  - 修正兩個誤判：「照片」只在「下列照片」「如照片所示」這類引用時才算缺圖；「代表一個」不再被當成「表一」。
  - 新增「轉檔殘留」：pandoc 等工具留下的行首「> 」、`\(`、`{.underline}` 等標記。
