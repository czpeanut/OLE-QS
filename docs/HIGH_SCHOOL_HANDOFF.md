# 高中題目交接：萃取高中段考卷，交回 OLE-QS 題庫

給負責「萃取高中段考題目」的 agent。照這份輸出，交回後題庫這邊會接手作答、分類、初審和上線。

- 基本格式和國中卷相同，**請先讀 `docs/QUESTION_FORMAT.md`**。
- 這份只寫高中卷**不同或要多注意**的地方，以及附圖怎麼交。
- 規則有衝突時，以本文件為準。

> 只交檔案，不要改這個 repo 的 `data/bank/`、`data/export/`，也不要改 Supabase。
> 金鑰放在 `.env.local`（不 commit），不要把金鑰或通行碼貼在對話或檔案裡。

---

## 1. 交件內容

交一個資料夾（或壓成 zip，或推到另一個分支的 `handoff/high_school/`）：

```
high_school/
  manifest.json                    ← 交件清單（見第 7 節）
  bank/                            ← 一份原卷一個 YAML
    doc_113_台中_台中一中_數學_g10s1e1.yaml
    doc_113_台中_台中二中_自然_物理_g10s1e1.yaml
  assets/                          ← 附圖 PNG，資料夾名＝卷 id
    doc_113_台中_台中一中_數學_g10s1e1/
      s1_3_f1.png
  sources/                         ← 原卷 PDF（必交，附圖位置對照用）
    高一/數學/113/1-1/台中/台中一中.pdf
  answers/                         ← （有的話）解答卷、詳解原檔，路徑同上
    高一/數學/113/1-1/台中/台中一中.pdf
```

- **一份原卷 → 一個 YAML**。一個 PDF 裡有好幾科、好幾個年級、或「題目卷＋解答卷」的，要拆開。
- 原卷是照片（JPG、PNG、HEIC）的，先依頁序合成一份 PDF 放進 `sources/`，`source_file` 指向這份 PDF，附圖位置也以它為準。
- 同一份卷有多個版本（原卷、清除字跡、重複下載）時只交一份，優先清除字跡的版本。
- 交件前跑檢查（第 8 節）。

## 2. `document`（和國中卷不同的地方）

| 欄位 | 高中卷 |
|---|---|
| `level` | **必填 `senior`**（國中卷沒有這欄） |
| `grade` | 10＝高一、11＝高二、12＝高三 |
| `subject` | 國文／英語／數學／自然／社會（同國中，英文一律寫「英語」） |
| `sub_subject` | 自然：**物理／化學／生物／地科**；社會：**歷史／地理／公民與社會**。合科卷不填 |
| `course` | 同一科有不同課程時必填：數學 `數A`、`數B`、`數甲`、`數乙`；選修寫課名，例如 `選修物理`、`探究與實作`。一般必修課不填 |
| `school_short` | 校名簡稱，例：`台中一中`、`台中女中`、`文華`、`衛道` |
| `school` | 正式全名，例：`臺中市立臺中第一高級中等學校` |
| `source_file` | `高X/<科目或子科>/<學年度>/<學期>-<段考>/<縣市>/<簡稱>.pdf`（科目或子科資料夾和 `sub_subject` 一致，例如 `物理`） |
| `scope_note` | 卷頭印的命題範圍（照抄；高中卷常寫「第一冊 1-1～2-3」） |
| `track` | （選填）班群或類組，例如 `自然組`、`社會組`、`數理資優班` |

**卷 id**：`doc_{學年度}_{縣市}_{簡稱}_{科目}[_{子科}][_{課程}]_g{年級}s{學期}e{段考}`

- 例：`doc_113_台中_台中一中_數學_g10s1e1`、`doc_113_台中_台中二中_自然_物理_g10s1e1`、`doc_113_台中_文華_數學_數A_g11s2e2`。
- 國中、高中靠年級（7～9、10～12）區分。完全中學（例如衛道）的國中部和高中部用同一個簡稱沒有關係。

**標題格式**：

```
title: {school} {學年度}學年度第{學期}學期第{段考}次定期評量 {高一|高二|高三}{科目}（{子科或課程}）科試題
```

- `exam_seq` 只收 1、2、3（期末考＝3）。
- 模擬考、複習考、學測模擬卷**先不要**混進來；要交的話另放 `bank_mock/`，並在 `manifest.json` 說明。

## 3. 題型與選項（高中卷常見的情況）

| 情況 | 寫法 |
|---|---|
| 單選題五選一（A～E） | `type: single`，**照原卷列 5 個選項**（高中卷允許 4 或 5 個） |
| 多選題 | `type: multiple`，選項照原卷（通常 5 個），答案寫成清單 `[B, D, E]` |
| 選填題（學測式，劃記數字） | `type: fill`，題幹保留格子編號（例：`⑬⑭`），答案寫成每格一個 `["3", "7"]` |
| 非選擇題、計算證明 | `type: calc`；有小題 (1)(2) 時照原卷寫在同一題，或拆成同題組的多題（題號用 `12`、`13`…，不要用 `12-1`） |
| 混合題（一組素材下有選擇也有非選） | 每小題一題，共用素材放 `group_stem`（＋`shared_asset`），各題 `type` 照實際題型 |
| 英文作文、翻譯 | `type: essay` |
| 配合題 | `type: matching`，共用的參考選項放 `group_stem` |

- 選項代號一律大寫英文字母，依卷面順序。原卷用 (1)(2)(3)(4) 或 ①②③ 當選項代號的，**改成 A、B、C、D**，並在 `review_note` 註明原代號。
- 英文聽力題不要輸出（題庫沒有音檔）。

## 4. 答案與詳解

- **答案**：只在有答案卷、解答卷或卷上印了答案時才填，`answer_status: verified`、`answer_source: answer_key`。
  沒有就留空，題庫這邊會用兩個模型作答，不一致時再加第三票；不要讓模型猜答案填進來。
- **詳解**：有官方詳解（解答卷附的解題過程）時填在 `explanation`，寫法和題幹一樣（Markdown＋LaTeX），照抄不要自己寫。
- **配分**：卷面有寫每題分數時可以填 `score`（數字），大題配分寫在 `sections[].name` 裡照抄即可。
- **送分、更正答案**：解答卷寫「送分」「(B)(C) 皆給分」時，`answer` 照實列出可接受的答案，並在 `review_note` 註明，例如 `解答卷：本題送分`。

## 5. 附圖怎麼交

**每張圖一個 PNG 檔**，放在 `assets/{卷 id}/`，YAML 用相對於 `assets/` 的路徑引用。

| 項目 | 規格 |
|---|---|
| 格式 | PNG，白底，不透明 |
| 解析度 | 從 PDF 以 **200 DPI** 以上裁切（照片卷以原圖解析度裁切），寬度至少 300 像素 |
| 範圍 | 包含圖內所有標號、座標、刻度、圖說（「圖(一)」），不要框到旁邊的題號、選項代號或下一題文字 |
| 方向 | 轉正再裁；整頁橫掃的頁面先把整頁轉正 |
| 檔名 | 題目附圖 `s{大題}_{題號}_f{第幾張}.png`；選項圖 `s{大題}_{題號}_opt{A-E}.png`；題組共用圖 `g{大題}_{第一題}_{最後一題}_f{第幾張}.png` |
| 不算附圖 | 校徽、浮水印、裝飾線、作答格線、答案欄 |

**每張圖都要寫 `crop`**（在原卷 PDF 的位置），審題台的「調整邊緣」要用它從原卷重裁：

```yaml
assets:
- key: s1_3_f1
  kind: figure          # figure（一般圖）／table（無法轉文字的表格）／chart（統計圖）
  file: doc_113_台中_台中一中_數學_g10s1e1/s1_3_f1.png
  crop:
    page: 1             # 原卷 PDF 第幾頁（1 起）
    rect: [72.0, 310.5, 290.2, 455.0]   # x0, y0, x1, y1，單位 PDF point（1/72 吋），原點在頁面左上角
```

- 用像素框換算：`rect = 像素框 × 72 ÷ DPI`。例：200 DPI 下框 `[200, 862, 806, 1264]` → `[72.0, 310.3, 290.2, 455.0]`。
- 頁面若有旋轉（`/Rotate`），以**轉正後**看到的頁面座標為準；PyMuPDF 的 `page.rect` 與 `get_pixmap(clip=…)` 就是這個座標。
- 選項是圖時放在該選項：`options: [{label: A, content: '', asset: {key: optA, file: …, crop: {…}}}]`。
- 題組共用圖放最上層 `shared_assets`，`used_by` 列出用到它的每一題，各題寫 `shared_asset: <key>`。
- **表格**：能轉成 Markdown 表格的一律轉成文字表格放題幹，不要截圖；只有複雜的合併儲存格、含圖的表才截圖（`kind: table`）。
- **化學結構式、電路圖、函數圖形、幾何圖**都截圖，不要試著用文字畫。

## 6. 公式（高中卷用得多）

一律用行內 LaTeX，前後加 `$`。題庫網站的公式渲染器支援以下寫法，**請只用這些**：

| 類別 | 指令 |
|---|---|
| 基本 | `\frac{a}{b}`、`\sqrt{x}`、`\sqrt[3]{x}`、`x^{2}`、`a_{n}`、`\times`、`\div`、`\pm`、`\cdot`、`\leq`、`\geq`、`\neq`、`\approx` |
| 幾何 | `\overline{AB}`、`\overrightarrow{AB}`、`\vec{v}`、`\overleftrightarrow{AB}`、`\angle`、`\triangle`、`\overparen{AB}`、`\perp`、`\parallel`、`\sim`、`\cong` |
| 函數 | `\sin`、`\cos`、`\tan`、`\log_{2}`、`\ln`、`\lim_{x \to 0}`、`\max`、`\min`、`\exp` |
| 大型運算 | `\sum_{k=1}^{n}`、`\prod`、`\int_{0}^{1}`、`\infty`、`\partial`、`\binom{n}{k}`、`C^{n}_{k}`、`P^{n}_{k}` |
| 集合、邏輯 | `\in`、`\notin`、`\subset`、`\subseteq`、`\cup`、`\cap`、`\emptyset`、`\forall`、`\exists`、`\mathbb{R}` |
| 矩陣、聯立 | `\begin{bmatrix}…\end{bmatrix}`、`\begin{vmatrix}…\end{vmatrix}`、`\begin{pmatrix}…\end{pmatrix}`、`\begin{cases}…\end{cases}`（列用 `\\`、欄用 `&`） |
| 化學 | `H_{2}SO_{4}`、`Fe^{3+}`、`\rightleftharpoons`、`\xrightarrow{\Delta}`、`\uparrow`、`\downarrow`、`\Delta H` |
| 希臘字母 | `\alpha`～`\omega`、`\Delta`、`\Sigma`、`\Omega`、`\theta`、`\lambda`、`\mu`… |
| 文字 | `\text{kJ}`、`\mathrm{mol}` |

- 一般數字和文字不要包進 `$`。上下標一律加大括號（`x^{2}`，不要寫 `x^2`）。
- YAML 字串裡的反斜線照寫一個就好（用 `|-` 區塊或單引號字串），不要寫成 `\\frac`。
- 渲染不了的寫法（例如 `\begin{array}`、`\overbrace`）不要用；真的需要時截圖當附圖。

其他文字規則（照抄原卷、畫線處 `<u>…</u>`、作答空格、題組、原卷錯字寫在 `review_note`、手寫痕跡不抄）和 `docs/QUESTION_FORMAT.md` 第 4 節相同。

## 7. 交件清單 `manifest.json`

```json
{
  "produced_by": "負責萃取的 agent 或專案名稱",
  "produced_at": "2026-11-10",
  "extractor": "使用的模型或方法，例如 vlm:gemini-3.7-flash",
  "papers": [
    {"id": "doc_113_台中_台中一中_數學_g10s1e1", "source_file": "高一/數學/113/1-1/台中/台中一中.pdf",
     "pages": 4, "questions": 22, "has_answer_key": true, "has_explanation": false,
     "notes": "第 3 頁右下角破損，第 18 題題幹有兩字看不清（已寫□）"}
  ],
  "skipped": [
    {"file": "原始檔名.pdf", "reason": "解答卷，已併入對應題目卷的答案"},
    {"file": "原始檔名2.pdf", "reason": "與 doc_… 為同一份卷的重複版本"}
  ]
}
```

`skipped` 請列出所有沒轉的原始檔與原因，題庫這邊用它確認沒有漏卷。

## 8. 交件前自我檢查

```bash
python scripts/check_bank_yaml.py high_school/bank --assets high_school/assets
```

- 檢查程式看到 `level: senior` 會改用高中規則：年級 10～12、高中子科、`course` 併入卷 id、單選允許 5 個選項。
- 錯誤（✗）要全部修掉；提醒（△）裡「會被品管剔除」的題目也請盡量修正。

## 9. 題庫這邊收到後會做的事（供參考，不用你做）

1. 查重：以卷 id 比對已收的高中卷。
2. 匯入前修正：網站的冊別、單元表目前只有國中（七上～九下），會加上高一～高三與 108 課綱高中單元表。
3. 作答：Gemini＋Qwen 兩模型，不一致時第三票；有答案卷的以答案卷為準，兩模型一致推翻答案卷時標「待判定」。
4. 單元分類、AI 初審（對照原卷找擷取錯誤與原卷錯誤）。
5. 上傳附圖、加進審題台，請老師審有初審意見的題目。
