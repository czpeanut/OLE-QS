# 作答模型比較（2026-09-30）

`scripts/answer_batch.py --eval`：10 份附答案卷的考卷（五科各 2 份）、365 題（選擇 348、填充 17，
134 題有附圖），一份卷一次呼叫，和答案卷比對。

| 模型 | 有回應的題數 | 對答案卷正確率 | 實測每題費用 |
|---|---:|---:|---:|
| gemini-3.7-flash（思考 low） | 365 | **90.1%** | NT$0.021 |
| qwen3.5-flash | 325 | 69.5% | NT$0.001 |
| qwen3.5-flash＋思考 | 285 | 84.6% | NT$0.0075 |
| qwen3.8-flash | 325 | 73.5% | NT$0.0013 |
| qwen3-vl-plus | 365 | 71.8% | NT$0.0028 |

- **答案卷本身有錯**：板橋八下數學第 5、15 題經人工驗算，答案卷錯、模型對。
  答案卷是擷取時由模型讀出來的（`answer_source: answer_key_vlm`），可能有對錯位。
  所以上表是正確率下限，而現有的 10,840 題答案也該交叉檢查。
- **Qwen 內容審查**：一份國一地理卷被 qwen3.5-flash、qwen3.8-flash 以
  `DataInspectionFailed`（輸入可能含不當內容）整份拒絕；qwen3-vl-plus 沒有被擋。
  台灣史地、公民題材可能常觸發。
- **Qwen 思考模式很慢**：一份卷 100～340 秒，還有一份輸出不成 JSON。
- 數學幾何題 Gemini（思考 low）只對 67%，qwen3.5-flash＋思考反而 76%；
  正式跑時數學應提高 Gemini 的思考等級。
