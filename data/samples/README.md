# 樣本與回歸測試集

擷取管線的「黃金測試集」。每次調整提示詞、換模型、改前處理，都用這裡的樣本跑一次評分，
用分數決定要不要採用 —— 沒有這套東西，調提示詞就只能憑感覺。

## 目錄

```
raw/        原始題本影像（未進版控，見下方說明）
expected/   人工確認過的標準答案（ground truth），YAML 格式
```

> `expected/` 只放**人工逐題確認過**的樣本。管線輸出（題庫本體）在 `data/bank/`，
> 兩者不可混放 —— 拿管線自己的輸出當基準，回歸測試就永遠是滿分。

## 為什麼 ground truth 用 YAML 而非 JSON

題幹含大量 LaTeX 反斜線，JSON 需逐一跳脫（`\\times`），手工維護極易出錯。
YAML 單引號字串內反斜線為字面值，可直接寫 `$\times$`。

管線輸出仍為 JSON。評分腳本把兩者都載入成 dict 後比對，格式差異不影響。

## 原始影像

`raw/` 未納入版控（見 `.gitignore`）—— 考卷影像檔大，且校內段考卷有著作權疑慮，不宜放進 git 歷史。
請自行把影像放到 `raw/`，檔名對應 `expected/` 的檔名加頁碼，例如：

```
raw/113-dayeh-g7-math-s1e1-p1.jpg
raw/113-dayeh-g7-math-s1e1-p2.jpg
raw/113-dayeh-g7-math-s1e1-p3.jpg
```

> ⚠️ 注意頁序：本樣本的來源截圖順序為 **第2頁 → 第3頁 → 第1頁**，
> 靠頁尾「【共 3 頁，第 N 頁…】」還原。管線不可信任檔名排序。

## 驗證

```bash
python scripts/validate_extraction.py data/samples/expected/*.yaml
```

結構驗證（配分總和、分大題題號連續性、選項數、LaTeX 閉合、資產完整性）
不需要知道正確答案，可直接對管線輸出執行，作為人工校對前的第一道防線。
